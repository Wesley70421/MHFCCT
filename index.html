1. Twin Towers — Absolute Value Function
Equation: $y = -2.4|x| + 225$
Domain: $\{x \mid -31 \le x \le 31, x \in \mathbb{R}\}$
Range: $\{y \mid 150.6 \le y \le 225, y \in \mathbb{R}\}$

Transformations

First, the basic graph $y=|x|$ opens downward because of a vertical reflection. Then, it has a vertical stretch by 2.4 to become steeper. Finally, it moves up by 225 units to reach the top of the bridge support.

Domain & Range

The domain shows the horizontal width of the bridge support beams. The range shows the height of the steel bridge support as a function of the horizontal distance from my right foot.

2. Cafe Relaxing — Quadratic Function
Equation: $y = 0.4x^2 + 0.3$
Domain: $\{x \mid -0.4 \le x \le 0.4, x \in \mathbb{R}\}$
Range: $\{y \mid 0.3 \le y \le 0.8, y \in \mathbb{R}\}$

Transformations

The original graph $y=x^2$ is vertically compressed by 0.4 to make the U-shape wider. After that, the graph moves up by 0.3 units to look like the height of the coffee table.

Domain & Range

The domain means the horizontal width of my arms when resting. The range means the height of my resting arms as a function of the horizontal distance from my right foot.

3. Classroom Entrance — Reciprocal Function
Equation: $y = \frac{1.5}{x - 1} + 2$
Domain: $\{x \mid 1 < x \le 2.5, x \in \mathbb{R}\}$
Range: $\{y \mid 2 < y \le 4, y \in \mathbb{R}\}$

Transformations

The parent function $y=\frac{1}{x}$ has a vertical stretch by 1.5. Then, the graph shifts to the right by 1 unit and moves up by 2 units to match the corner of the door frame.

Domain & Range

The domain cannot include $x=1$ because of the asymptote line. The range shows the curve height of the classroom doorway frame as a function of the horizontal distance from my right foot.

4. Giordano Facade — Reciprocal Squared Function
Equation: $y = -\frac{2}{x^2} + 5$
Domain: $\{x \mid -3 \le x \le 3, x \neq 0, x \in \mathbb{R}\}$
Range: $\{y \mid 0 \le y \le 4.8, y \in \mathbb{R}\}$

Transformations

The graph $y=\frac{1}{x^2}$ is reflected vertically so it opens down. Next, it has a vertical stretch by 2 and shifts up by 5 units to fit the layout of the building pillars.

Domain & Range

The domain cannot have $x=0$ because it is an asymptote. The range means the actual height of the glass window facade as a function of the horizontal distance from my right foot.

5. Friends Group Selfie — Cubic Function
Equation: $y = 0.2(x - 1)^3 + 1.5$
Domain: $\{x \mid -1 \le x \le 3, x \in \mathbb{R}\}$
Range: $\{y \mid 1.2 \le y \le 1.8, y \in \mathbb{R}\}$

Transformations

The function $y=x^3$ is vertically compressed by 0.2 to become flatter. After that, it shifts right by 1 unit and moves up by 1.5 units to trace the line of our shoulders.

Domain & Range

The domain shows the total width of my friends standing next to each other. The range shows our shoulder line heights as a function of the horizontal distance from my right foot.

6. Campus Corridor — Tangent Function
Equation: $y = 0.5\tan(x) + 1.5$
Domain: $\{x \mid -1.5 < x < 1.5, x \in \mathbb{R}\}$
Range: $\{y \mid 0 \le y \le 3, y \in \mathbb{R}\}$

Transformations

The basic tangent graph $y=\tan(x)$ is vertically compressed by 0.5 to make the curve less steep. Then, it moves up by 1.5 units to align with our normal eye level.

Domain & Range

The domain is limited between the two sides of the hallway wall. The range shows the height of the hallway lines as a function of the horizontal distance from my right foot.

7. Sunway Lake — Sinusoidal Function
Equation: $y = 0.4\sin(\pi x) + 1.6$
Domain: $\{x \mid 0 \le x \le 2, x \in \mathbb{R}\}$
Range: $\{y \mid 1.2 \le y \le 2.0, y \in \mathbb{R}\}$

Transformations

The wave graph $y=\sin(x)$ is compressed horizontally by $\frac{1}{\pi}$ to make the waves closer. Then, it is compressed vertically to 0.4 and shifts up by 1.6 units.

Domain & Range

The domain covers one full wave of how we stand and sit. The range shows the top height of our heads as a function of the horizontal distance from my right foot.

8. Perspective Ceiling — Exponential Function
Equation: $y = 0.5(2^x) + 1$
Domain: $\{x \mid 0 \le x \le 4, x \in \mathbb{R}\}$
Range: $\{y \mid 1.5 \le y \le 9, y \in \mathbb{R}\}$

Transformations

The exponential function $y=2^x$ is compressed vertically by 0.5 to match the slow slope of the roof. Then, the whole graph moves up by 1 unit.

Domain & Range

The domain shows the horizontal distance from the back to the front of the ceiling. The range shows the ceiling height as a function of the horizontal distance from my right foot.

9. Environmental Post — Logarithmic Function
Equation: $y = 0.8\log_{10}(x + 1) + 1$
Domain: $\{x \mid 0 \le x \le 0.8, x \in \mathbb{R}\}$
Range: $\{y \mid 1 \le y \le 1.2, y \in \mathbb{R}\}$

Transformations

The basic log function $y=\log_{10}(x)$ shifts left by 1 unit so it does not get an error at $x=0$. Then, it is vertically compressed by 0.8 and moves up by 1 unit.

Domain & Range

The domain starts at 0 to show where my body is standing. The range shows the height of my moving arm as a function of the horizontal distance from my right foot.
