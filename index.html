My Time in Malaysia

1. Twin Towers — Absolute Value Function
Equation: $y = -2.4|x| + 225 \quad \{-31 \le x \le 31\}$
Domain: $\{-31 \le x \le 31, x \in \mathbb{R}\}$
Range: $\{150.6 \le y \le 225, y \in \mathbb{R}\}$

Personal Connection

This photo was taken when I went to Kuala Lumpur with my friends. We visited the iconic Petronas Twin Towers at night, and I was amazed by the huge steel bridge connecting the two towers. This memorable trip with friends inspired me to model the shape of the bridge support using mathematics.Photo taken by Wesley

Transformations

First, the basic graph $y = |x|$ opens downward because of a vertical reflection. Then, it has a vertical stretch by 2.4 to become steeper. Finally, it moves up by 225 units to reach the top of the bridge support.

Domain & Range

The domain shows the horizontal width of the bridge support beams. The range shows the height of the steel bridge support as a function of the horizontal distance from my body (right foot).

2. Collar – Square Root Function
Equation: $y = \sqrt{1.8x + 1} + 1 \quad \{-0.468 \le x \le 0\}$
Domain: $\{-0.468 \le x \le 0, x \in \mathbb{R}\}$
Range: $\{0.3966 \le y \le 2, y \in \mathbb{R}\}$

Transformations

The parent function $y = \sqrt{x}$ is first shifted left by 1 unit (inside the square root). It is then vertically stretched by a factor of 1.8. Finally, it is shifted up by 1 unit. The domain is restricted to $\{-0.468 \le x \le 0\}$ to model the specific part of the roti tissue.

Domain & Range

The domain represents the horizontal distance range of the roti tissue being modeled. The range shows the height of the roti tissue, from the minimum value of approximately 0.3966 (at $x = -0.468$) to the maximum value of 2 (at $x = 0$).

3. The length of the top of the head — Sine Function
Equation: $y = 2\sin(2.2x + 1.25) - 1.25 \quad \{0 \le x \le 0.25\}$
Domain: $\{0 \le x \le 0.25, x \in \mathbb{R}\}$
Range: $\{0.648 \le y \le 0.75, y \in \mathbb{R}\}$

Personal Connection

This photo was taken at school while playing hide and seek with my friends. I was holding a map, trying to find a good hiding spot. The wavy movement of my head while looking around and moving reminded me of a sine wave, so I decided to model the height of the top of my head as a sine function.Photo taken by Wesley

Transformations

The parent function $y = \sin(x)$ is horizontally compressed, phase shifted, vertically stretched by 2, and shifted down by 1.25. Within the restricted domain $\{0 \le x \le 0.25\}$, the function only captures a small increasing portion of the sine wave.

Domain & Range

The domain represents the horizontal distance range of my movement while playing. In this interval, the range (height of the top of my head) varies from approximately 0.648 to the maximum of 0.75.

4. Beams – Quartic Function
Equation: $f(x) = 0.05x^4 - 0.05x^2 + 2.5 \quad \{-1 \le x \le 1.3\}$
Domain: $\{-1 \le x \le 1.3, x \in \mathbb{R}\}$
Range: $\{2.4875 \le y \le 2.5583, y \in \mathbb{R}\}$

Transformations

This is a quartic function (degree 4). It can be seen as a transformation of $y = x^4$: vertically compressed, combined with a downward quadratic term $-0.05x^2$, and shifted upward by 2.5 units. The even powers create a symmetric bowl shape, but the domain restriction makes it model one side of the roti tissue curve.

Domain & Range

The domain represents the horizontal distance range of the beams. In this interval, the function reaches its minimum value of approximately 2.4875 (near the local minimum) and maximum value of approximately 2.5583 at $x = 1.3$.

5. The Rim of the Cup — Linear Reciprocal Function
Equation: $y = -\dfrac{0.1}{x} + 0.5 \quad \{-1.6 \le x \le -1\}$
Domain: $\{-1.6 \le x \le -1, x \in \mathbb{R}\}$
Range: $\{0.5625 \le y \le 0.6, y \in \mathbb{R}\}$

Personal Connection

This photo was taken when I was with my friend at a milk tea shop in Penang. While drinking bubble tea, I noticed the curved rim of the plastic cup created an interesting shape. This fun moment with my friend in Penang inspired me to model the rim of the cup using a reciprocal function.Photo taken by Welsey

Transformations

This is a rational function based on the parent function $y = \frac{1}{x}$. It is vertically compressed, reflected over the x-axis (negative sign), and then shifted up by 0.5 units. The domain is restricted to $\{-1.6 \le x \le -1\}$ to model the specific part of the cup rim.

Domain & Range

The domain represents the horizontal distance range in the negative region. Within this interval, the function values (height of the cup rim) range from the minimum 0.5625 (at $x = -1$) to the maximum 0.6 (at $x = -1.6$).

6. The Steering Wheel – Exponential Function
Equation: $y = 0.2133 \cdot 0.2844^x \quad \{-1 \le x \le -0.5\}$
Domain: $\{-1 \le x \le -0.5, x \in \mathbb{R}\}$
Range: $\{0.40 \le y \le 0.75, y \in \mathbb{R}\}$

Transformations

This is an exponential decay function. The base 0.2844 (between 0 and 1) causes the function to decrease as x increases. It is vertically scaled by 0.2133. The domain is restricted to $\{-1 \le x \le -0.5\}$ to model the specific portion of the steering wheel curve.

Domain & Range

The domain represents the horizontal distance range. In this interval, the function value (height) decreases from the maximum 0.75 (at $x = -1$) to the minimum approximately 0.40 (at $x = -0.5$).

7. The Distance between Two Heads — Tangent Function
Equation: $y = \tan(1.02x) + 1.4 \quad \{-0.6 \le x \le 0.79\}$
Domain: $\{-0.6 \le x \le 0.79, x \in \mathbb{R}\}$
Range: $\{0.6981 \le y \le 2.4417, y \in \mathbb{R}\}$

Personal Connection

This photo was taken by the river next to the beautiful Pink Mosque in Malaysia with my friend. The scenery was stunning, and while we were chatting and taking photos, I noticed the changing distance between our heads as we moved. This memorable moment inspired me to model the vertical distance between our heads using a tangent function.Photo taken by Wesley

Transformations

The parent function $y = \tan(x)$ is horizontally stretched/compressed by a factor of $\frac{1}{1.02}$ and then shifted upward by 1.4 units. The domain is restricted to $\{-0.6 \le x \le 0.79\}$ to capture the specific increasing portion of the tangent curve for the distance between two heads model.

Domain & Range

The domain represents the horizontal distance range between the two heads. In this interval, the function increases from the minimum value of approximately 0.6981 (at $x = -0.6$) to the maximum value of approximately 2.4417 (at $x = 0.79$).

8. The distance between the tips of the noses – Logarithmic Function
Equation: $f(x) = 0.0673 \ln(x + 0.5) + 2.0216 \quad \{-0.45 \le x \le 0.225\}$
Domain: $\{-0.45 \le x \le 0.225, x \in \mathbb{R}\}$
Range: $\{1.82 \le y \le 2.00, y \in \mathbb{R}\}$

Transformations

This is a logarithmic function based on the parent function $y = \ln(x)$. It is horizontally shifted left by 0.5 units (inside the logarithm), vertically compressed by a factor of 0.0673, and then shifted up by 2.0216 units. The domain is restricted to $\{-0.45 \le x \le 0.225\}$ to model the specific portion of the distance between the tips of the noses.

Domain & Range

The domain represents the horizontal distance range of the roti tissue. In this interval, the function increases from approximately 1.82 (at $x = -0.45$) to nearly 2.00 (at $x = 0.225$).

9. Leg length of a cat – Rational Function (Reciprocal Square)
Equation: $f(x) = \dfrac{0.4}{x^2} \quad \{-1 \le x \le -0.5\}$
Domain: $\{-1 \le x \le -0.5, x \in \mathbb{R}\}$
Range: $\{0.4 \le y \le 1.6, y \in \mathbb{R}\}$

Transformations

This is a rational function based on the parent function $y = \frac{1}{x^2}$. It is vertically compressed by a factor of 0.4. The domain is restricted to the negative interval $\{-1 \le x \le -0.5\}$ to model the specific portion of the leg length of a cat curve.

Domain & Range

The domain represents the horizontal distance range in the negative region. As $x$ moves from -1 to -0.5, the function value (height) increases from the minimum 0.4 (at $x = -1$) to the maximum 1.6 (at $x = -0.5$).
