1. Twin Towers — Absolute Value Function
Equation: $y = -2.4|x| + 225$
Domain: $\{x \mid -31 \le x \le 31, x \in \mathbb{R}\}$
Range: $\{y \mid 150.6 \le y \le 225, y \in \mathbb{R}\}$

Transformations

First, the basic graph $y=|x|$ opens downward because of a vertical reflection. Then, it has a vertical stretch by 2.4 to become steeper. Finally, it moves up by 225 units to reach the top of the bridge support.

Domain & Range

The domain shows the horizontal width of the bridge support beams. The range shows the height of the steel bridge support as a function of the horizontal distance from my body.

2. Collar – Square Root Function
Equation: $y = \sqrt{1.8x + 1} + 1 \quad \{-0.468 \le x \le 0\}$
Domain: $\{-0.468 \le x \le 0, x \in \mathbb{R}\}$
Range: $\{0.3966 \le y \le 2, y \in \mathbb{R}\}$

Transformations

The parent function $y = \sqrt{x}$ is first shifted left by 1 unit (inside the square root). It is then vertically stretched by a factor of 1.8. Finally, it is shifted up by 1 unit. The domain is restricted to $\{-0.468 \le x \le 0\}$ to model the specific part of the roti tissue.

Domain & Range

The domain represents the horizontal distance range of the roti tissue being modeled. The range shows the height of the roti tissue, from the minimum value of approximately 0.3966 (at $x = -0.468$) to the maximum value of 2 (at $x = 0$).

3. The length of the top of the head – Sine Function
Equation: $y = 2\sin(2.2x + 1.25) - 1.25 \quad \{0 \le x \le 0.25\}$
Domain: $\{0 \le x \le 0.25, x \in \mathbb{R}\}$
Range: $\{0.648 \le y \le 0.75, y \in \mathbb{R}\}$

Transformations

The parent function $y = \sin(x)$ is horizontally compressed, phase shifted, vertically stretched by 2, and shifted down by 1.25. Within the restricted domain $\{0 \le x \le 0.25\}$, the function only captures a small increasing portion of the sine wave.

Domain & Range

The domain represents the horizontal distance range of the roti tissue. In this interval, the range (height) varies from approximately 0.648 to the maximum of 0.75.
